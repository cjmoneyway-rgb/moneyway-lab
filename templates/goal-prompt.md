# Four-part goal prompt (Moneyway Lab™ AI Operator 101, Move #4)

Moneyway Lab™'s original framework. Copy, fill in every bracket, and paste into your AI tool.

```
GOAL:            [What are we making, for whom, and why?]
CONTEXT:         [Files or info to read first, e.g. tone-of-voice.md, facts.md]
LIMITS:          [Length, format, musts, and at least one "never"]
DONE LOOKS LIKE: [File name/location or format, required parts, how we'll check it]

Plan first and ask me questions before you build.
```

## Quick check before you send
- [ ] GOAL names an audience **and** a purpose
- [ ] CONTEXT points to at least one file instead of retyping it
- [ ] LIMITS includes "facts only from facts.md; if missing, ask"
- [ ] DONE LOOKS LIKE can be checked with a yes/no by someone else
- [ ] Nothing private (customer data, passwords, card numbers) is in the prompt
- [ ] Anything that sends, spends, or publishes stays with a human
