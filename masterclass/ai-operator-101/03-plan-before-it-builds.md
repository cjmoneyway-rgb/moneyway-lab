# #3 Make it plan before it builds

> **The win:** Ten to twenty minutes of planning saves hours of "that's not what I meant."

## Permission modes: who's driving?
Claude Code lets you choose how much it can do on its own:

| Mode | What it does | Use when |
|---|---|---|
| **Manual** | Asks before every change | You're learning or the work is sensitive |
| **Accept edits** | Changes files without asking each time | You trust the plan and want speed |
| **Auto** | Claude decides when to check with you | Everyday work |
| **Plan** | **Makes a plan first and changes nothing until you approve** | Anything new or bigger than a quick fix |
| Bypass permissions | Never asks | Experts in a safe sandbox only. Not for beginners. |

**Rule:** if it'll take AI more than a few minutes, start in **Plan**.

## What planning looks like
You ask:
> "Add an About page to my website with my story and a small photo gallery."

A good plan doesn't just start building. It reads your files first, then asks what it can't know:

> *"There are no photos in the project and your story is one paragraph. What should the gallery use?"*
> - ◉ **Placeholders + draft story (recommended):** I'll write a longer draft and leave spots for real photos
> - ○ **I'll provide photos:** put them in an `images/` folder
> - ○ **Stock photos from the web:** needs a license check
> - ○ Other

Those questions are where your output goes from generic to *yours*.

## The Moneyway rule: 10–20 minutes
```
 PLAN        10–20 min   ← answer the questions, fix the plan
 BUILD       AI does it
 REVIEW      you check it before it goes public
```
Don't skip the plan to save time. Fixing a bad build costs more than planning would have.
