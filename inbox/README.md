# inbox/: drop zone

Put anything here: screenshots, photos of your screen, voice memo transcripts, links, rough ideas.
You don't need to sort it.

**Nothing is processed automatically.** When you're ready, start a Claude Code session in this repository and say:
> **"Process the inbox."**

Claude then follows the routing rules in `/CLAUDE.md`. It identifies each item, files it in the right place
(rewriting outside material in our own words), logs outside sources, and reports what went where and what
it still needs from you. Originals stay here until you say delete.

Tips
- Name files with a hint, e.g. `podcast-ep12-notes.txt` or `book-ch3-ideas.md`.
- Don't drop passwords, customer lists, or private financial documents here.
