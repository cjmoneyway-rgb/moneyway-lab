# inbox/: drop zone

Put anything here: screenshots, photos of your TV, voice memo transcripts, links, rough ideas.
Don't sort it. That's Claude's job.

Then start a session and say:
> **"Process the inbox."**

Claude will follow the routing rules in `/CLAUDE.md`. It will tell you where each item went,
what it turned into, and what it still needs from you. Originals stay here until you say delete.

Tip: name files with a hint, e.g. `podcast-ep12-notes.txt` or `book-ch3-ideas.md`.
